# Python IT & Security Scripts

This repository contains small Python scripts focused on network testing and security automation.

## Core Tools
- **`password_checker.py`**: A script that evaluates password strength based on standard security policies.
- **`ping_scanner.py`**: A basic network troubleshooting tool to check device connectivity.
- **`backup_tool.py`**: An automation utility that secures critical data through automated backups.
- **`caesar_cipher.py`**: A classic symetric cryptography tool implementing data encryption and decryption mechanics.

## Requirements
- Python 3.x
- Standard macOS/Linux Terminal
